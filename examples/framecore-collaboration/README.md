# Przykładowy film współpracy

`project.json` to edytowalny zapis projektu odpowiadającego [filmowi MP4](../../assets/framecore-collaboration.mp4). Czas: 15 s; format: 1920 × 1080, 30 FPS. Katalog `assets` zawiera materiały, do których odwołuje się projekt.

Aby utworzyć wersję gotową do pracy w lokalnym edytorze:

```bash
python framecore.py sample
python framecore.py editor
```

W menu projektów wybierz „TABASCO CREATIVES + FRAMECORE — wspólny film”. Polecenie tworzy nowy projekt i nie nadpisuje istniejących zmian. Możesz zmieniać teksty, animacje, ikony i dźwięk, a następnie ponownie eksportować.
